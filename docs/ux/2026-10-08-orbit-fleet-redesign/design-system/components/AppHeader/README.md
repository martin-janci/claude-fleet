# AppHeader

The 44 px header: the Orbit mark and name, the ⌘K command field, one quiet button per account with its remaining quota, and the automation summary with Pause all.

**The consumer provides** the accounts (address, health dot, quota text; a limit shows in `status-waiting` with when it resets) and the automation count and spend today.

**Do**
- Keep ⌘K and ⌘P opening the same quick switcher.
- Keep Pause all one click away whenever automation runs.

**Don't**
- Don't animate the header logo, except at the end of startup (the splash mark shrinks into it) and the 16 px Orbit while a host is still connecting.
