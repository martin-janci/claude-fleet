# OrbitMark

The Orbit Fleet mark: a hub, one orbit and three hosts on a slate tile; the amber host is the one waiting on you.

**The consumer provides** a size. Use 22 px in the header, 16 px in the status bar and rows, 28 px beside a page title, 72 px and up on empty and error screens.

**Do**
- Draw it from `brand-ink`, `brand-light` and `brand-amber` on the 108-unit grid, exactly as `assets/Logos/orbit-mark.svg`.
- Use `orbit-mark-light.svg` on a white tile and `orbit-glyph-template.svg` for the macOS menu bar.

**Don't**
- Don't recolour the amber host or add a fourth satellite.
- Don't put the mark on `accent`.
