# StatusBar

The 25 px footer: overall health, downloads, the hub address, a slow host still connecting, and the shortcuts sheet.

**The consumer provides** the health summary (its `title` carries the versions), the hub address and any background item still loading.

**Do**
- Use only the 16 px Orbit or the Comet here as a loader.

**Don't**
- Don't put actions that change state in the footer.
