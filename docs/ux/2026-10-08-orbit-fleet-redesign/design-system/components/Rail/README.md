# Rail

The 68 px left rail: Control, Inbox, Sessions, Work, Automation, Accounts, Toolkit, then Settings at the bottom.

**The consumer provides** the current page (`aria-current="page"`) and the Needs you count for the Inbox badge (`status-waiting` fill, `on-waiting` text).

**Do**
- Keep Control first (⌘E). Every item's `title` names its shortcut.
- Badge only the Inbox, and only with the Needs you count.

**Don't**
- Don't add items without a decision; merging Sessions into Inbox and Toolkit into Accounts is still an open decision.
