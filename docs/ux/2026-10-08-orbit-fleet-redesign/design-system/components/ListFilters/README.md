# ListFilters

The head of the left list: pane title with its count, the search field, the Filters button with active filter chips, and the grouping menu.

**The consumer provides** the pane title, a count sentence ("4 need you"), the active filters as removable chips, and the current grouping (state, host, project, org, account).

**Do**
- Keep this panel on every list screen (Inbox, Sessions, Work). It is the left filter and grouping panel and it stays.
- Show each active filter as a chip with ×; the Filters button carries their count.

**Don't**
- Don't fold filters or grouping into a popover or a hidden menu.
