# Logos

The Orbit mark: a hub, one orbit and three hosts; the amber host is the one waiting on you. Drawn on the 108-unit grid that fleet-mobile's launcher icon uses.

- `orbit-mark.svg`: the primary mark, `brand-light` glyph and `brand-amber` host on the `brand-ink` tile. Use it everywhere by default.
- `orbit-mark-light.svg`: for a white surface; slate glyph (#1B2430) and a darker amber host (#B45309) on a white tile with a #D9D9D9 edge.
- `orbit-glyph-template.svg`: single ink, black, no tile; the macOS menu-bar template image and Android 13 themed icon. The system recolours it.
- `icon-source.svg`: the 1024 px app-icon source in claude-fleet (`src-tauri/icons/icon-source.svg`), inset to the macOS 824 px tile. Regenerate every desktop size with `pnpm tauri icon`.
