Never AI

Jev and the LLM never decide, pre-select or rank these:
  • Approving a push or a permission
  • Device trust, roles, shares, access level
  • A task's organisation (assign_org)
  • Mission autonomy and other settings changes
  • Mission complete and “Verified”: CI, tests and commits only
  • Force kill and Clean up readiness: git only
  • Host or account by numbers (limit, disk, latency)
  • Priority, size, and the order of Needs you
  • Add-host checks and error reports: facts
