# F2 — fleet launches sessions via `ag` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every host fleet provisions gets the `ag` launcher and a `cl` command (`claude --yolo`), and fleet's pane command uses `ag` whenever the host has no `cl` of its own — with Claude sessions behaving exactly as before.

**Architecture:** The pane-command chain (`cl --resume … || cl --session-id … || cl …`) is untouched; only its inline fallback learns a middle branch: no `cl` on PATH but `$HOME/.local/share/ag/ag` present → `cl() { "$HOME/.local/share/ag/ag" claude --yolo "$@"; }`. Provisioning embeds `tools/ag` in the binary (`include_str!` table, like `PAGE_FILES`), stages it under `~/.local/share/fleet/ag-src`, and runs its `install.sh --alias 'cl=claude --yolo'`. Installing `ag` is optional: any failure is a provisioning *warning*, never an error, because the pane fallback still reaches plain `claude`. A new setting `provision.install_ag` (default on) turns the step off.

**Tech Stack:** Rust (fleet-core), bash (tools/ag), Svelte/TS settings mirror, JSON declarative pages.

**Spec:** `docs/superpowers/specs/2026-09-29-multi-harness-agents-design.md` §5.1, §5.3 ("Launch"), roadmap F2. Builds on F1 (`feat/ag-launcher`, PR #404); this branch `feat/fleet-launch-via-ag` is stacked on it.

## Global Constraints

- Claude sessions must behave exactly as before on a host WITHOUT ag: every existing pane-command test keeps passing unchanged (`tmux.rs` `pane_command_*`, `sessions/tests.rs`, `sessions/lifecycle_tests.rs`, `repair*.rs`), and `scripts/hub-e2e.sh`'s fake-claude chain still reaches `--session-id`.
- A user's own `cl` on PATH always wins (today's behaviour).
- `ag` path in the pane fallback is absolute: `"$HOME/.local/share/ag/ag"` (never bare `ag` — The Silver Searcher ships a binary of that name; and a freshly created `~/.local/bin` may not be on the cached toolchain PATH).
- The provisioned alias is exactly `cl=claude --yolo`.
- Setting key `provision.install_ag`, Bool, default `"true"`.
- `ag` is optional: provisioning never fails because of it; failures surface as a warning (full provision: the host result's `detail`; content refresh: a `tracing::warn!`).
- Staging dir `~/.local/share/fleet/ag-src` (carries a `.fleet-managed` marker, which `install.sh` copies into `~/.local/share/ag`).
- fleet-core conventions: every interpolated shell value goes through `crate::shell::quote` / `remote_path`; spawn only via `crate::proc`; no `eprintln!/println!/dbg!` (use `tracing`); never hold the `Store` mutex across `.await`.
- `tools/ag` stays bash 3.2 compatible (see `tools/ag/README.md`); `scripts/ag-test.sh` must pass under `bash` and `/bin/bash`.
- Commit messages: Conventional Commits (`feat(…)`, `fix(…)`, `test(…)`, `docs(…)`) — `scripts/release.sh` builds the changelog from them.

/// Step 5 (F2): stage fleet's `ag` launcher under [`AG_STAGE_DIR`] (with a
/// `.fleet-managed` marker, which the installer copies along) and run its
/// installer: `~/.local/share/ag`, `~/.local/bin/ag`, a config with the
/// `cl` alias unless the user already has one, and the `cl` shim.
/// Optional by design — `None` when installed, otherwise a warning and
/// provisioning carries on: the pane command's fallback still reaches
/// plain `claude` (see `tmux::CL_FALLBACK`).
pub async fn provision_ag(ssh: &dyn SshExec, host: &str) -> Option<String> {
    let files = AG_FILES.iter().map(|(rel, body)| {
        let dir = match rel.rsplit_once('/') {
            Some((d, _)) => format!("{AG_STAGE_DIR}/{d}"),
            None => AG_STAGE_DIR.to_string(),
        };
        (dir, format!("{AG_STAGE_DIR}/{rel}"), body.to_string())
    });
    let marker = (
        AG_STAGE_DIR.to_string(),
        format!("{AG_STAGE_DIR}/{MANAGED_MARKER}"),
        marker_content(),
    );
    for (dir, path, body) in files.chain(std::iter::once(marker)) {
        if let Err(e) = write_host_file(ssh, host, &dir, &path, &body).await {
            return Some(format!("ag launcher not installed: {}", e.message));
        }
    }
    match crate::ssh::run_shell(ssh, host, &ag_install_script(), AG_INSTALL_TIMEOUT).await {
        Ok(out) if out.status.success() => None,
        Ok(out) => {
            let text = format!(
                "{}{}",
                String::from_utf8_lossy(&out.stdout),
                String::from_utf8_lossy(&out.stderr)
            );
            let tail: Vec<&str> = text.lines().filter(|l| !l.trim().is_empty()).collect();
            let tail = tail[tail.len().saturating_sub(3)..].join(" | ");
            Some(format!(
                "ag launcher not installed (install.sh exit {}): {}",
                out.status.code().map_or_else(|| "signal".to_string(), |c| c.to_string()),
                tail.chars().take(300).collect::<String>()
            ))
        }
        Err(e) => Some(format!("ag launcher not installed: {}", e.message)),
    }
}
